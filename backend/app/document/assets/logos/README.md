# Logos por empresa

El informe usa el logo de la columna **Logo** de la lista del cliente
(`data/companies.json` → `in_companies.logo_key`). Para activar el logo de una
empresa basta con dejar aquí un archivo `.png`, `.jpg` o `.jpeg` con el nombre
del logo en minúsculas y con guiones. **No hay que tocar código.**

Mientras falte el archivo de un logo, el informe usa el logo por defecto
(`../invotecsa_logo.png`).
